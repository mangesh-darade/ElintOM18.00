# API KEY

Another solution that we provide is the **API key** approach. This API Key can be generated by logging to the UI and going to **profile settings > API Keys**

<figure><img src="/files/EabKbeLcGl57KiIbs1ue" alt=""><figcaption></figcaption></figure>

Under API you will find the option to generate **API Key,** click on generate and you have the API key available.  This is a permanent key which can be re-generated or deactivated as per user preference.
